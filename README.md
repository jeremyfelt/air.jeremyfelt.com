# air.jeremyfelt.com

Tracking what my air is like now at air.jeremyfelt.com.

## Installing the PWA on Android Devices

To install the Progressive Web App (PWA) on your Android device, follow these steps:

1. Open the Chrome browser and navigate to air.jeremyfelt.com.
2. Tap the menu icon (three dots) in the top right corner of the browser.
3. Tap "Add to Home screen."
4. You will be prompted to name the shortcut before tapping "Add."

Once added, the app icon will appear on your home screen, allowing you to access the latest AQI number directly.

## Dynamic Icon Functionality

The custom icon on the Android home screen dynamically displays the latest Air Quality Index (AQI) number from `data/last-observation.json`. This feature enables you to quickly glance at your phone to check the current air quality without opening the app.

Please note, the dynamic icon update depends on periodic background updates and may not reflect real-time changes instantly.
